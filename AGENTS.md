# FJG Task Manager Development Guide

## Source of truth

This repository is the development source for FJG Task Manager. The installed vault plugin at `.obsidian/plugins/fjg-task-manager/` is build output.

Markdown task workspaces are authoritative. The dashboard and desktop catalog are derived views.

## Required checks

Before every release:

```bash
npm run check
npm run package:release
```

The root-level `main.js`, `manifest.json`, `styles.css`, and `versions.json` are generated by `npm run build` for BRAT compatibility and must match `apps/obsidian-plugin/`.

## Safety boundaries

- Never write outside the configured active and archive task roots.
- Never resolve a task mutation by ambiguous title alone.
- Keep the desktop catalog bound to loopback, authenticated, read-only, origin-restricted, and rate-limited.
- Preserve `task_id` through renames, archive moves, migration, and protocol requests.
- Keep `task` as the only automatic tag. Never add status tags.
- Migration must remain dry-run-first, staged, and repeat-safe.
- Do not change or connect to the legacy Taskboard, iOS app, clippers, bridge, or launcher.
- Do not migrate live data or cut over the launcher without Franklin's explicit approval.

## Releases

Use semantic versions. A GitHub release must include:

- `main.js`
- `manifest.json`
- `styles.css`
- `versions.json`
- the Obsidian plugin ZIP;
- the Chrome extension ZIP.

The Chrome extension is loaded separately and pairs with the desktop plugin using the local catalog token.
